# smina runtime directory

Place a compatible smina executable at `tools/smina/smina`, or configure
`MDS_SMINA_COMMAND` to use a system installation. The executable is excluded
from Git and is not distributed by the iScreeM source repository.

smina contains code under Apache-2.0 and GPL-2.0. A redistributed binary that
contains GPL-covered components must be accompanied by the notices and
corresponding source required by GPL-2.0.
